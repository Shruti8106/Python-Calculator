🧮 Python Calculator

A simple command-line calculator built using Python.

✨ Features

- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero handling
- Exit option

🛠️ Technologies Used

- Python 3
- Visual Studio Code

📚 Concepts Used

- Functions
- While loops
- If-elif-else statements
- User input
- Type conversion

🚀 How to Run

1. Install Python 3.
2. Download "Calculator.py".
3. Open the terminal in the project folder.
4. Run:

python Calculator.py
